## 🚀 How to Run

### 🔹 PHP Practicals
1. Install XAMPP
2. Place folder inside `htdocs`
3. Start Apache & MySQL
4. Open in browser:

http://localhost/folder-name


### 🔹 Servlet / JSP Practicals
1. Install Apache Tomcat
2. Deploy project inside `webapps`
3. Start Tomcat server
4. Access via:

http://localhost:8080/project-name
